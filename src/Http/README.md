# keel/http

PSR-15 `Pipeline`, `HttpException` family, `Responder` (JSON, redirects, streams and
Server-Sent Events), `ArgumentResolver` with `#[FromQuery]` / `#[FromBody]`, `Hydrator` with
validation, `BodyParser`, `CorsMiddleware`, `RequestIdMiddleware`, `TrustedProxiesMiddleware`,
`TrustedHostsMiddleware`, `SecurityHeadersMiddleware`, `BodyLimitMiddleware`,
`ServerTimingMiddleware`, `HttpCacheMiddleware`, `#[Deprecated]`, `MethodOverrideMiddleware`,
`SapiEmitter`. Read-only split of
[AloneCoder/keel](https://github.com/AloneCoder/keel); issues and pull requests go there.
Documentation: [docs/en/http.md](https://github.com/AloneCoder/keel/blob/main/docs/en/http.md).
