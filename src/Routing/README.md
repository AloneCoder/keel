# keel/router

`#[Route]`/`#[Get]`/`#[Post]`... attributes, `#[Prefix]`, `#[Middleware]`, `#[Status]`, placeholder
constraints, FastRoute-style group-count matching, 405 with `Allow`, HEAD fallback, URL generation
and a cache that is a plain PHP array. Read-only split of
[AloneCoder/keel](https://github.com/AloneCoder/keel); issues and pull requests go there.
Documentation: [docs/en/routing.md](https://github.com/AloneCoder/keel/blob/main/docs/en/routing.md).
