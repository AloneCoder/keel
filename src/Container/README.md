# keel/container

PSR-11 2.0 container: constructor autowiring, `#[Inject]`, `#[TaggedIterator]`, `#[Lazy]`
(PHP 8.4 lazy ghosts), `#[Transient]`, `#[Alias]`, `#[Tag]`, `Resettable` services and a compiler
that generates one method per service. Read-only split of
[AloneCoder/keel](https://github.com/AloneCoder/keel); issues and pull requests go there.
Documentation: [docs/en/container.md](https://github.com/AloneCoder/keel/blob/main/docs/en/container.md).
